# PocketHLE-GDI 0.4.6-wince.1 pre-release

Adds an opt-in Windows CE desktop to the existing PocketHLE-GDI fork, retaining
GTShell and Android SD Card support. Windows GUI/CLI and a signed universal Android
APK are supplied with a portable profile-template ZIP.

- Classic GDI frames, caption buttons, dragging and a `#3A6EA5` desktop.
- Explorer and child applications share a composed desktop. Child exit reveals
  the Explorer/taskbar, and input ownership follows the window receiving it.
- Portable Explorer menu, icon-list, folder-history, Run/Browse and window cleanup
  fixes; caption icons now use real class/window resources.
- CE6 image and private registry/filesystem profiles on Windows and Android.
- Native profiles select the untouched image's `Windows/explorer.exe`. Native
  shell DLL mapping, desktop/taskbar registration, SIP geometry and owned API-set
  metadata support its bootstrap; Portable Explorer remains separate.
- Typed CEDB volumes/records for the original shell, bounded strsafe Ex path
  operations and shared clipboard snapshots with process-local guest allocations.
- Native children inside tab controls compose correctly. Default window painting
  preserves Control Panel icons and neighbouring windows.
- Shared emulated UTC clock and event subscriptions; time and device-name changes
  can launch subscribed applications without changing the host clock.
- Seven HLE Control Panel applets using original image resources and shared
  device settings; byte-counted strsafe and CommandBar alignment compatibility.
- Android image selection/import and a separate `com.pockethle.gdi` package.

This pre-release implements CE APIs; it does not boot an original kernel or
provide every OEM driver/CPL. The minimal separate `xplorer.exe` has outstanding
compatibility differences. Android packaging checks do not establish physical
device compatibility. CerfDemo was not rerun for this delivery.
Original Explorer compatibility remains experimental: complete shell interaction,
general native API-set marshalling and every image application are not certified.

Microsoft images and Microsoft-derived Portable Explorer binaries are supplied
by the user and excluded from public release assets. A private backup can be
created locally using the profile packaging tool.
