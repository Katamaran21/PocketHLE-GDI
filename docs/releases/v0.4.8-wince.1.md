# PocketHLE-GDI 0.4.8-wince.1 pre-release

Integrates upstream `guizmox/PocketHLE` through commit
`f7c3ee5b1c8fe703fed9c1c97f78364c7471b459` while retaining the Windows CE
desktop, original Explorer support and separate Windows/Android launchers.
The original Explorer and application files are supplied by the user.

- Original and Portable Explorer use the shared desktop compositor, classic
  caption buttons, window dragging and the `#3A6EA5` background. Pointer and
  keyboard events reach the owning UI thread; idle shell waits remain parked.
  Closing a folder or child application reveals the current desktop beneath it.
- Desktop shortcuts, registered document verbs and Run/Browse resolve mounted
  guest applications with their arguments. ListView display caches retain icon
  and text metadata without repeating unchanged native callbacks.
- Control Panel retains its applet icons and Close command. Owner, System and
  Volume & Sounds have tab pages, transactional Apply/Cancel behavior and live
  device settings. Message boxes and supported applet windows can be moved.
- The original CE6 `cmd.exe` uses a classic console window. Console input,
  standard streams, parent/child console ownership, command execution and
  process teardown share the same device session. A separate `wince6-cmd`
  profile is included in the public templates.
- Registry-selected system sounds use the mounted CE WAV files and shared PCM/
  ADPCM decoder. Virtual device suspend/resume preserves guest state and keeps
  frontend Stop and resume input available.
- Runtime fixes include bounded API-set/device queries, shared clipboard and
  typed CEDB records, synchronous common-control notifications, native COM
  factory/IBindCtx ownership, ARM/Thumb callback continuations, PE/process
  versions and checked CRT/GDI operations used by built-in applications.
- Upstream GLES 2.0, Compact Framework, toolhelp, HTC sensor, storage and launcher
  changes are retained. Native DLL data imports initialize before EXE entry;
  runtime export forwarders keep bounded graph resolution and cycle detection.
- Android keeps application ID `com.pockethle.gdi`, uses versionCode **23**, and
  checks this fork's releases for updates. Windows, Linux and Android artifact
  names consistently identify PocketHLE-GDI. PR checks build the platforms,
  run workspace/ARM callback tests, and package public profiles and source.

This remains an experimental HLE implementation. It does not boot the CE kernel
or supply every OEM driver/service. Complete HTML rendering/navigation, TAPI,
general native API-set marshalling and every application in an image are not
certified. EmulatorStub still requires an absent Device Emulator DMA provider.
RDP connection support is outside this release's scope.

Public profile ZIPs contain templates and import instructions. Microsoft CE
images, application binaries and private device data are excluded from release
assets. A private backup can be created separately with the profile packaging
tool. Android build checks do not establish physical device compatibility.
