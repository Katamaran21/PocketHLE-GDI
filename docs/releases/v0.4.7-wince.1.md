# PocketHLE-GDI 0.4.7-wince.1 pre-release

Continues support for original Windows CE applications through the existing HLE
desktop and shared device profiles. Windows GUI/CLI and signed Android packages
use the same API implementations; Android's package versionCode is now 22.

- Control Panel has a Close button in its original command bar. File/View and
  applet icons retain their work-area layout, and the guest handles WM_CLOSE.
- Desktop CE shortcuts and registered document verbs resolve to real guest
  executables, preserving arguments, quoting and literal percent characters.
- Native Explorer's cached image/text display fields are retained per subitem,
  avoiding repeated icon metadata callbacks during selection repaint.
- Registry-selected native COM factories and IBindCtx support the original
  PegHelp/IESample browser objects, with owned references and ARM/Thumb callbacks.
- Built-in application compatibility includes PE subsystem/process versions,
  signed MulDiv, full-range pointer probes, CE font combobox insertion, counted
  binary BSTR allocation and the system locale alias used by Pocket Word.
- Private Pocket Word template defaults are migrated once; existing values and
  later user deletions are preserved. WinINet queries report real handle ancestry
  and the local transport access state.

This remains a pre-release. Complete HTML rendering/navigation, TAPI dial-up
applications and all OEM applets are not implemented. Supplied CE executables,
DLLs, image hives and documents remain unchanged; writes use the private device
overlay. The public profile-template ZIP contains no Microsoft CE binaries.
